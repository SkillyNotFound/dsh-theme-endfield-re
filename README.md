# dsh-theme-endfield-re

参考《明日方舟：终末地》官网视觉风格的 DeepSeek Harness 主题插件。

本项目由 [dsh-theme-endfield](https://github.com/ymh0000123/dsh-theme-endfield) 1.1.5 分叉而来，此后独立维护。仓库内为完整主题，可直接安装、修改与测试。

## 主题风格

奶油纸底，墨黑文字，以信号黄与武陵青为强调色，界面通体直角，呈工业编辑风。

插件仅作用于客户端，通过主题令牌与样式覆盖实现，不修改应用自身代码。

## 主要功能

**配色与形态**
提供谷地黄、武陵青两套强调色，直角与圆角两种形态，以及可选的磨砂玻璃表面。

**等高线背景**
以程序生成的标量场绘制真实等值线，整屏铺满强调色细线，闭合环线相互嵌套。支持动态流动，帧率（24 / 60 / 120 FPS）与速度（1x / 2x / 4x）可分别调整，并可在 Canvas 与 Worker / WebGL 两种绘制后端之间切换。系统开启「减少动态效果」时保持静态渲染。

**中央散景**
使等高线在对话中轴线附近逐渐虚化，画面四周保持清晰；新建会话页则以画面中心为焦点。虚化程度与压暗程度可分别设置。

**鼠标轨迹**
指针附近的等高线产生局部形变，随后缓慢恢复。默认关闭。

**背景水印**
以 ENDFIELD 大字作为水印，默认只出现在新建会话页，可设置为在对话页持续显示。

**启动动画**
仿官方主视觉的加载画面：黑底，左缘进度轨自上而下填充，刻度与读数随填充端下移。

**雷霆大字**
任务开始与结束时在屏幕中央显示提示大字，可附加缩放入场动画，点击屏幕任意位置即可提前关闭。

**音频通知**
任务开始、任务结束、需要回应、出错等场景的提示音。音频由宿主进程播放，因此页面最小化或切换至其他应用时同样可闻。总开关默认关闭。

设置入口为「设置 › 终末地主题设置」。界面文案随 DSH 的语言设置即时切换，支持中英文。全部设置由 DSH 自身的设置服务持久化，与页面地址及端口无关，在浏览器与桌面端均可跨重启保留。

## 发展方向

一是保持与 DSH 宿主版本同步，及时跟进应用侧标记与接口的变动，避免样式钩子在宿主升级后静默失效。

二是延续既有的视觉语言，继续打磨等高线背景及其衍生表现，中央散景即为此方向上的第一项工作。

三是补齐测试覆盖，使主题在宿主持续迭代的前提下保持可用。

## 安装

```bash
dsh plugin --profile web add github:SkillyNotFound/dsh-theme-endfield-re
```

安装后重启或重新加载对应 profile 生效。卸载：

```bash
dsh plugin --profile web rm dsh-theme-endfield-re
```

修改插件文件后，客户端部分刷新页面即可生效；宿主部分只在 profile 启动时加载一次，需整个进程重启。

## 开发

```bash
node check.js     # 样式表静态校验
node selftest.js  # 校验器自检
npm test          # 完整测试套件
```

测试覆盖样式不变量、配色、设置页、浏览器渲染、等高线几何与性能预算。部分用例需要本机安装 Chrome 或 Edge。
